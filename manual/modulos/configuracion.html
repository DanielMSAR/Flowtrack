Módulo: Administración del Sistema y Usuarios

Gestión de acceso de operadores y actualización automática de software

← Volver al Índice

1. Descripción General

Este espacio contempla la administración de operadores con acceso al sistema, asignación de contraseñas mediante encriptación segura y la comprobación de nuevas versiones en el repositorio oficial de GitHub.

2. Actualización Automática del Sistema

  1. En el menú lateral, acceda a SISTEMA ➔ Actualizar.
  2. El sistema comparará la versión local instalada contra la última versión publicada en el repositorio de GitHub.
  3. Si existe una nueva versión disponible, descargará automáticamente los scripts actualizados y reiniciará la aplicación.

3. Gestión de Usuarios y Seguridad

Cada acción relevante (altas, modificaciones, pesajes y movimientos) registra el ID del usuario en sesión activa. Las claves de acceso se encriptan con bcrypt para garantizar la máxima protección de datos.
